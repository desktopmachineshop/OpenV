OpenV System Architecture

Requirements, traceability and V&V platform, with a host-side agent suite. Archify spec: docs/diagrams/openv-system.architecture.json

Platform

  • Railway deploys the release branch
  • Single Go API; React SPA
  • Postgres with numbered migration ledger

Agent suite

  • agent_runs rows are the queue
  • Server never calls model providers
  • Writes land as proposals for review

Security

  • API: auth middleware, org/project RBAC, rate limiting
  • Session cookie + X-Org-ID, optional Google OIDC
  • Hashed, revocable worker / runner keys
  • Rate-limited public interview endpoints
