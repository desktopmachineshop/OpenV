# Table

Dense rows for coverage, matrices, runs and member lists, inside a panel.

## What the consumer provides
A `<table class="ov-table">` with a `<thead>`, one ref column first where rows are artifacts, and state as StatusChips. Mark the selected row with `aria-selected="true"`.

## Rules
- Header row sits on `surface-sunken`, cells on `surface`, one hairline between rows.
- Numbers use tabular figures (built in).
- More than about 12 rows: add a filter above, not a longer page.
